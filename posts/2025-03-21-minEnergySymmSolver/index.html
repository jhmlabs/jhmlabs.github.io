Energy Minimizers, Symmetric Operators, and Sylvester’s Systems, and Lagrange Multipliers

We report on some progress on a technical problem which has been delaying our work.

Given arbitrary vectors \(x,y \in {\mathbf{R}}^N\), we’re looking for a python code to yield the minimal \(L^2\)-energy symmetric matrix \(A\) which solves the linear equation \(Ax=y\). Thus we study the optimization problem of minimizing \(||A||^2\) subject to the linear constraints \(Ax=y\) and \({}^t A = A\).

We introduce the Lagrangian \[L(A, \lambda, \mu):=\frac{1}{2}{tr}({}^t A A) + {}^t \lambda \cdot (Ax-y) ~+ \langle\mu, {}^tA -A \rangle, \] where \(\lambda\) is \(N \times 1\) vector, \(\mu\) is \(N\times N\) matrix, and \(\langle, \rangle\) is scalar-valued dot product between the \(N \times N\) matrices. Computing gradients we have \[\nabla_A L = A + \lambda \cdot {}^t x + \nabla_A \langle \mu, {}^t A -A \rangle.\] The gradient of the third term \(\nabla_A \langle \mu, {} ^t A - A \rangle\) is computed in explicit coordinates with \(A=(a_{ij})\), such that \[\langle \mu, {}^t A -A \rangle = \sum_{ij} \mu_{ij} (a_{ij}-a_{ji}).\] To compute this gradient, we have \[\nabla_A \langle \mu, {}^t A - A \rangle = ( \frac{\partial}{\partial a_{kl}} \sum_{ij} \mu_{ij} (a_{ij}-a_{ji}) )_{kl} = (\mu_{kl}-\mu_{lk})_{kl} = \mu - {}^t \mu.\]

Therefore we find \[\nabla_A L = A + \lambda .{}^t x + \mu - {}^t \mu.\] Moreover we have \[\nabla_\lambda L = Ax -y = 0\] and \[\nabla_\mu L = {}^t A - A = 0\] according to the constraints.

The transpose of \(\nabla_A L=0\) yields \[\lambda = \frac{1}{{}^t xx} (-y - (\mu - {}^t \mu)x ) \] and \[A = ({}^t x x)^{-1} [ y.{}^tx + (\mu-{}^t \mu) x .{}^tx ] + {}^t \mu -\mu .\] Thus we find \(A\) is a function of \({}^t \mu - {}^t \mu\), and we look to uniquely define \(\mu - {}^t \mu\) rather than \(\mu\).

Obviously \[{}^tA = ({}^t x x)^{-1} [ x.{}^ty + x.{}^tx({}^t \mu-\mu) ] + \mu -{}^t \mu .\] The symmetry constraint \({}^t A = A\) implies \[ y.{}^tx -x.{}^t y = (\mu - {}^t \mu)(||x||^2 Id+x.{}^t x) + (||x||^2 Id+x.{}^tx) (\mu - {}^t \mu) . \]

Now the final question is how to solve for the matrix \({}^t \mu - \mu\)?

In the literature, this type of linear system of the form \[BX+XB=C\] is known as a “Sylvester equation”, where \[B:=||x||^2 Id+x.{}^t x\] and \[C:=y.{}^tx -x.{}^t y\] and \[X:=\mu - {}^t \mu\] in our setting. Our particular Sylvester equation has a unique solution since the operator \(B\) is invertible. Using the SciPy solver, we would write

X := solve_sylvester(B,B,C)

Then we construct the operator \(A\) by the formula \[A := (||x||^2)^{-1} [ y.{}^tx + X. x .{}^tx ] - X.\]

By definition \(A\) is symmetric, since \(X\) solves the necessary Sylvester equation, and is the minimal energy solution solving the original system \(Ax=y\).

import numpy as np
from scipy.linalg import solve_sylvester

# x is 1xN np.array
# y is 1xN np.array
# returns the minimal energy symmetric NxN matrix A which maps Ax=y

def minEnergySymmSolve(x,y):
    n = len(x[0])
    id = np.eye(n)

    scalar1 = np.dot(x,x.T)[0][0]
    matrix1 = np.dot(x.T, x)
    matrix2 = np.dot(scalar1, id)
    B = matrix1 + matrix2

    matrix3 = np.dot(y.T, x)
    matrix4 = np.dot(x.T, y)
    C = matrix3 - matrix4

    # Solve for X
    X = solve_sylvester(B, B, C)

    scalar2 = scalar1**-1
    matrix5 = np.dot(X.T, matrix1)
    matrix6 = matrix3 + matrix5
    matrix7 = np.dot(scalar2, matrix6)
    matrix8 = matrix7 - X
    A = matrix8

    return A
x = np.array([[2.0, 3.0, 5.0]])
y = np.array([[-1.0, -0.5, -0.2]])

print(minEnergySymmSolve(x,y))
